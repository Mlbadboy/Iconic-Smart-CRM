❓ Frequently Asked Questions

How do I reset my password? ▼
Click "Forgot Password" on the login page, enter your email, and follow the instructions sent to your inbox.
What are the demo credentials? ▼
Admin: admin@iconic-crm.com / admin123
Manager: manager@iconic-crm.com / manager123
Sales: sales@iconic-crm.com / sales123
How do I create an API key? ▼
Go to Settings → API Keys → Create New Key. Choose your permissions and expiration date. Save the key securely as you won't be able to see it again.
Can I use this on mobile devices? ▼
Yes! The CRM is fully responsive and works on all devices (phones, tablets, desktops). Touch targets are optimized for mobile use.
How do I integrate with Shopify? ▼
Create an API key, then use our Shopify webhook integration. Check the API_INTEGRATION_GUIDE.md for complete code examples.
Is there keyboard navigation support? ▼
Yes! Use Tab to navigate, Enter to activate, Escape to close dialogs. Press Alt+A on login to auto-fill demo credentials.
Where can I find the documentation? ▼
All documentation is available in the project folder:
  • WORKFLOW_GUIDE.md - Complete workflows
  • API_INTEGRATION_GUIDE.md - API documentation
  • ACCESSIBILITY_GUIDE.md - Accessibility features
  • INTEGRATION_QUICK_START.md - Quick setup
