## 💡 **What Each Popup Shows**

### **⌨️ Keyboard Shortcuts**
```
• Tab - Navigate forward
• Shift+Tab - Navigate backward
• Enter/Space - Activate element
• Escape - Close dialogs
• Alt+A - Auto-fill login
• Ctrl+K - Quick search
```

### **🔑 API Key Help**
```
1. Login to dashboard
2. Go to Settings
3. Click "API Keys"
4. Create new key
5. Copy and save securely

Test at: http://localhost:7000/index.html
```

### **📱 Android Setup**
```
1. Add Retrofit dependency
2. Create API client
3. Make requests to API

Full examples in: API_INTEGRATION_GUIDE.md
```

### **🔔 Webhooks**
```
1. Login to dashboard
2. Go to Settings → Webhooks
3. Create webhook
4. Enter URL
5. Select events
6. Save secret

Events: order.created, order.shipped, etc.
```

### **🛒 Shopify Integration**
```
1. Generate API key
2. Install webhook in Shopify
3. Configure integration
4. Add API key

Full code in: API_INTEGRATION_GUIDE.md
```
